# first_project
Пример использования бота Aiogram 3.x Telegram Stars Payments
Базовый бот для пожертвований, демонстрирующий возможности Telegram Stars Payments. На основе Aiogram 3 с некоторыми полезными ускорителями и асинхронными (неблокирующими) библиотеками. А также с базовой настройкой архитектуры.
